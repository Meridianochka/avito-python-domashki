# avito-python-domashki

Домашки по курсу Python.

## Зависимости

Нужен Python 3.9 или новее. Сторонних библиотек нет, устанавливать ничего не надо.

## Запуск

hw1 — пять отдельных файлов:

```
python3 hw1/task_1.py
```

hw2 — читает `Corp_Summary.csv` и спрашивает номер отчёта (1, 2 или 3):

```
cd hw2
python3 main.py
```

# Avito Analytics Academy — Python

Учебный репозиторий с домашними заданиями по курсу Python.

## Структура

- `hw1/` — коллекции: множества, списки, словари
- `hw2/` — функции: отчёты по выгрузке сотрудников

## Требования

- Python 3.9 или новее

Внешних зависимостей нет, используется только стандартная библиотека,
поэтому ничего устанавливать не нужно. Проверить версию:

```
python3 --version
```

## Запуск

### hw1

Каждое задание — отдельный файл, запускается независимо:

```
python3 hw1/task_1.py
python3 hw1/task_2.py
python3 hw1/task_3.py
python3 hw1/task_4.py
python3 hw1/task_5.py
```

### hw2

Программа читает `Corp_Summary.csv` и строит отчёт по выбранному варианту:

1. иерархия: департаменты и входящие в них отделы
2. сводка по департаментам: численность, минимальная, максимальная и средняя зарплата
3. та же сводка, сохранённая в `summary.csv`

```
cd hw2
python3 main.py
```

После запуска программа спросит номер варианта (1, 2 или 3).

Отчёт можно собрать и из кода:

```python
from main import make_report

make_report(2)
```
